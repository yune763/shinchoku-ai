# 進捗管理AI メンバー導入ガイド（各自PCで動かす版・Windows）

このガイドは、**自分のPCで進捗管理AIを動かす**ための手順です。
データ（ゴール・メンバー・ツール管理など）は共有データベース(Firestore)に集約されるので、
各自ローカルで動かしても**全員で同じ情報を共有**できます。AI機能は**各自のClaude（Maxプラン）**で動きます。

---

## できること
- 進捗の閲覧・入力・チャット（全員共有）
- 「作業ログで進捗・子タスクを更新」などのAI機能を、**自分のPCのClaude Max**で利用
- Claude Code / Cursor を作業フォルダで起動

---

## 準備（管理者からもらうもの）
- **FIREBASE_SERVICE_ACCOUNT**（共有DB接続用の鍵・1行のJSON）
  - ※機密情報です。安全な方法（パスワードマネージャ等）で受け取ってください。
- **Claude の Maxプラン**アカウント（AI機能を使う場合）

---

## インストール（1行だけ）

1. スタートメニューで **「PowerShell」** を開く
2. 次の1行を貼り付けて Enter（Node.js・Git・Claude CLI・本体を自動で用意します）:

   ```powershell
   irm https://raw.githubusercontent.com/yune763/shinchoku-ai/main/setup.ps1 | iex
   ```

3. 途中で **FIREBASE_SERVICE_ACCOUNT** の貼り付けを求められたら、管理者から受け取った値を貼り付けて Enter
   （手元に無ければ空のまま Enter → 後で `shinchoku-ai\.env` に設定でもOK）

> うまく動かない場合: 一度 PowerShell を閉じて開き直し、もう一度同じ1行を実行してください
> （インストール直後はコマンドのパスが反映されないことがあります）。

### Mac の場合
1. 「ターミナル」を開く（Spotlight で「terminal」と検索）
2. 次の1行を貼り付けて Enter:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/yune763/shinchoku-ai/main/setup.sh | bash
   ```

3. 途中で **FIREBASE_SERVICE_ACCOUNT** を聞かれたら貼り付け（Homebrew導入時にMacのパスワードを求められることがあります）
4. 完了後、デスクトップの「進捗管理AIを起動.command」をダブルクリック
   （初回は右クリック →「開く」で実行許可が必要な場合があります）

---

## 初回のみ：Claude にログイン（AI機能を使う人）
PowerShell で次を実行し、画面の指示に従って Maxアカウントでログインします:

```powershell
claude
```

---

## 使い方（毎回）
- デスクトップの **「進捗管理AIを起動」** をダブルクリック
- 数秒後、ブラウザで **http://localhost:3000** が開きます
  （開かない場合は手動でこのURLを開く）
- 使い終わったら、起動時の黒いウィンドウを閉じればアプリは停止します

---

## よくある質問

**Q. 他の人が追加したゴールは見られますか？**
はい。全員が同じ FIREBASE_SERVICE_ACCOUNT を設定していれば、データは共有されます。
画面を更新(リロード)すると最新の内容になります。

**Q. インストール先はどこ？**
`C:\Users\<あなた>\shinchoku-ai` です。

**Q. 更新したいときは？**
もう一度インストールの1行を実行すると最新版に更新されます（データはそのまま）。

**Q. ブラウザだけで使いたい（インストールしたくない）**
管理者から共有されたデプロイ版URLを開き、「新規登録」→管理者の承認、でも使えます。
ただしブラウザ版では、各自PCのClaude/Cursor起動や、ローカルClaudeでのAI処理は使えません。
